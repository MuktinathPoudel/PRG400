Course Information

Course Number and Name: PRG 402 Mobile Programming Applications

Units: 3

Length of Class: 8 Weeks

Course Description:
This course introduces students to mobile application development using JavaScript, jQuery, HTML, and associated client-side tools. Students learn to use these programming tools to develop applications designed for use in mobile environments. Students also use mobile application frameworks and development environments to create web pages that also collect data and interface with a database. The user interface and user experience is also be discussed.

Course Learning Outcomes (CLOs)

Outcome Description PLOs
1 Demonstrate basic programming skills and understanding of Javascript, JQuery, and HTML. 3
2 Explain the importance of UX/UI design in mobile applications 4
3 Describe the requirements gathering process in mobile application design and the importance of user input. 2, 5
4 Write program code using client-side tools in Javascript, JQuery, HTML, and CSS. 3
5 Execute the use of mobile application frameworks and development environments that collect data and interface with a database. 3

About

Implementing this learning, I want to make my knowledge strong in mobile app development by practicing real-world projects and continuously exploring UI/UX and JavaScript-based frameworks.

Key Takeaways

  • Hands-on experience with client-side tools like HTML, CSS, JavaScript, and jQuery.
  • Understanding the development flow of mobile web applications from design to database connectivity.
  • Awareness of best practices in UI/UX for optimal mobile user experience.

Builded Platforms
